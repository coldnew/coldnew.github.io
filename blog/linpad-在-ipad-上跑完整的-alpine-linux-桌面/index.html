LinPad: 在 iPad 上跑完整的 Alpine Linux 桌面

發表於 2026-11-14

最近看到這篇推文，作者設計了一個名為 LinPad 的 iOS 程式，可以用來跑 Alpine Linux 作為桌面，這對於想把 iPad 當作筆電的我而言是有趣的項目，於是就嘗試了一下

Vali Neagu@AmbsdOP𝕏

Laptop-class hardware. I wanted a Linux desktop.

I built LinPad OS - Linux for iPad.


  • Real terminal + desktop windows

  • No jailbreak. No VM.

Free & open source (pre-release).
Your iPad. Your hardware.linpados.com#Linux #iPad #OpenSource

如何安裝

我們可以到專案 repo 找到對應的 ipa 檔案，透過 iLoader 下載到你的 iPad 上，同時也需要安裝 StickDebug 打開 JIT 支援才行

fspecii/LinPadPublic

LinPad — Linux for iPad. A real Linux desktop on the iPad: native windowed desktop with tiling and workspaces, real Linux apps (Firefox, VS Code, Thunar, VLC) as native windows, ARM64 JIT, GPU via Venus/Metal, keyboard + trackpad + touch.

使用心得

由於這還是早期專案，因此目前使用下來是稍微堪用，但我還是無法透過他將 iPad 當作我主力桌面來使用，或許還要思考怎樣的場景可以用到他

目前遇到最大的問題應該是程式出問題時候不知道怎樣除錯，因為這個系統既沒有 system log 也沒有 dmesg ，整個結構有點複雜

但參考他的設計，是目前所有在 iPadOS 上跑 Linux 最合理的手段，不管是影片播放、聲音、網路都支援非常良好，如果可以做到不依賴 JIT 的話就更好，但是估計要這樣做到的話，需要將 Linux 上所有套件重新編譯或是特別處理來達到可以在 iPad OS 上執行

會測試這個另外一個原因是我使用的 iPad 是 iPad Air M3 ，只有 6GB 記憶體，如果記憶體更多的話還可以另外測試 Henge 這個讓你可以在 iOS/iPad OS 上跑原生 MacOSX 的專案
