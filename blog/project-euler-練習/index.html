Project Euler 練習

發表於 2015-10-15 分類：程式練習
#clojure

Project Euler 是一個很不錯的程式練習網站，和 LeetCode 相比起來，Project Euler 的 題目比較偏向數學，也就是只要你數學不錯，用紙筆也是可以進行解題。對於工程師來說， 數學的磨練是不可以停止的，因此我重新紀錄我解 Project Euler 題目的經過。

在這邊我使用 Clojure 來進行解題，你可以在 這裡 找到完整程式碼，大部分的程式都盡 可能用 函數式 的方式來解決。

001: Multiples of 3 and 5

If we list all the natural numbers below 10 that are multiples of 3 or 5, we get 3, 5, 6 and 9. The sum of these multiples is 23.

Find the sum of all the multiples of 3 or 5 below 1000.

題目要求的是找出 0 ~ 1000 中所有 3 或是 5 的倍數的總和，因此我們需要一個函式去判 斷輸入數值是否為 3 或 5 的倍數。

接下來產生 1 ~ 1000 的序列 (sequence)，並透過 map reduce 的方式即可取得相加結果。

另外一種解法則是，我們找出所有 3 的倍數進行相加並加上所有 5 的倍數，由於這個過程 中會多加上一組 (3 * 5) 的倍數，因此把剛剛的結果減掉 15 的倍數們即是答案了。
