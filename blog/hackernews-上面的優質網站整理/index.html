HackerNews 上面的優質網站整理

Aug 7, 2026

最近剛好看到 Read HN twice a day for the last decade. Here's my list of S-Tier HN links 這篇文章，列出了許多作者在 HackerNews 上面看到不錯的網站，因此來整理一下。

機器學習相關

Transformer Explainer

*把一個 GPT-2 用 ONNX Runtime 跑在你的瀏覽器裡*，打字進去就能即時看到 embedding、attention、輸出機率怎麼流動；還能拉 temperature、top-k、top-p 滑桿看分佈變化。

K-Means Explorable

k-means 分群互動解說。一步步展示質心怎麼移動、怎麼收斂

Visual Guide to Vision Transformer

ViT 捲動式圖解，分 14 步：切 patch → 展平 → embedding → 加 CLS token 與位置編碼 → multi-head attention → 殘差 → 分類。

A Visual Introduction to Machine Learning (R2D3)

用「分辨舊金山 vs 紐約的房子」教決策樹。scrollytelling 的標竿級作品，順帶把 overfitting、false positive/negative 講得極清楚。

MLU-Explain

Amazon Machine Learning University 出的視覺論文集，目前 16 篇：神經網路、線性/邏輯迴歸、決策樹、隨機森林、Precision & Recall、ROC/AUC、交叉驗證、Bias-Variance、Double Descent、Equality of Odds 等。品質整齊，適合當工具書查。

Graph Game

拖放小遊戲：*自己把神經網路架構接線接出來*。目前五關 —— RNN、LSTM Cell、GRU Cell、ResNet Block、Deep RNN。

Neural Networks from Scratch

一步步自己搭出一個神經網路。CC0 授權，可自由取用。

Understanding Neural Network, Visually

用手寫數字辨識當例子，講神經元的權重與閾值、每層如何辨識越來越複雜的特徵。

How FAISS Works

向量檢索深入圖解：為什麼暴力搜尋在十億級會爆掉、IVF 如何用 K-Means 切分空間跳過無關區塊、Product Quantization 如何把 512 bytes 壓成 8 bytes 還保留距離語意、IVFPQ 疊加，以及 GPU 加速的四個技巧。做 RAG 的人該讀。

數學相關

Seeing Theory

布朗大學的機率統計互動教材，由 Daniel Kunin 在大學部時期用 D3.js 做的。六章：基本機率、複合機率、機率分佈、頻率學派推論、貝氏推論、迴歸分析。可以自己丟硬幣、擲骰、抽牌看期望值與變異數怎麼跑出來。

Immersive Linear Algebra

Ström、Åström、Akenine-Möller 三人合著，號稱「世界第一本圖表全互動的線性代數書」。十章從向量、內積、外積、高斯消去、矩陣、行列式、秩、線性映射到特徵值特徵向量

晶片 / 硬體

ChipBuilder

Select.Supply（Laurentiu R.）做的遊戲：*從 AND/OR/NOT 邏輯閘開始，一路蓋出加法器、多工器、ALU、暫存器，最後組成 CPU 並寫組合語言跑在自己造的處理器上。* 就是可玩版的《Nand2Tetris》。

Mvidia

Yale 的 CS/數學學生 jaso1024 做的「從一顆電晶體開始組出 GPU」遊戲，2026 年 4 月在 HN 爆紅。規劃五章，目前第 1、2 章共 48 關可玩。

FT: Microchips

《金融時報》的互動長篇，主題是半導體製造流程。

Lumafield: Health Wearables 拆解

工業 CT 掃描機廠商 Lumafield 的「First Article」專欄。用 CT 不破壞地透視消費電子內部 ：AirPods Pro 2/3、Vision Pro、Quest Pro/3、Dexcom、Oura Ring、18650 電池、濾水器、甚至番茄醬瓶蓋。有剖面圖、材質密度圖、3D 體積渲染、新舊對比

網路 / 系統

200ms — The Node Book

把「一次 HTTP request 的 200 毫秒」拆成分幕動畫：DNS 解析 → TCP 建連 → TLS 握手 → 核心層 → Node.js event loop → Postgres 查詢 → 回程。

Networking & The Internet（Faza 的 Mental Models）

篇幅驚人：13 個章節、標示 71 分鐘閱讀 ，附互動模擬器。從電報一路講到光纖，涵蓋封包交換 vs 電路交換、IP 定址與路由、TCP 可靠性機制、DNS、WWW、TLS。核心觀點很好：每個協定都是「為了補某個具體的洞」而生，不是憑空設計出來的。

Rate Limiting 演算法視覺化

smudge.ai 出品。三種做法：Fixed Window、Sliding Window（含實務用的近似版 floating window）、Token Bucket。用一個模擬 Twitch 聊天室的互動示範，可以按 Hit 手動灌請求看行為差異。

Algorithm Visualizer

開源平台（React + Node.js），可以看多種語言寫的演算法 逐行執行時的視覺化狀態 ，也能自己貢獻新的演算法與視覺化。涵蓋資料結構、排序、圖論等分類。網站是 SPA 抓不到內容，說明取自其 GitHub repo。

Elliptic Curve Cryptography 圖解

作者是應用密碼學碩士生，寫來鞏固自己所學。從 RSA/DH 的侷限講起 → 曲線幾何 → 點加法 → 純量乘法 → 有限體 → ECDH/ECDSA/ECIES 三個協定 → 為什麼金鑰更短更快 → 量子威脅。可以拉參數看曲線變形、點擊看幾何關係。

圖形 / 遊戲開發

The Vulkan Kitchen

同樣是 Tom Salembien。 用「專業餐廳廚房」當貫穿比喻 講 Vulkan 圖形管線，九個章節從 Instance/Device/Queue、Swapchain、Pipeline、Shader、Buffer/Descriptor 到 Command Buffer 與同步。

Modern Culling Techniques

krupitskas 寫的渲染剔除技術全景：距離/背面/視錐剔除 → 遮擋剔除（硬體查詢、軟體、Hi-Z pyramid、two-pass）→ 螢幕尺寸剔除、PVS、Portal → GPU-driven 的 indirect draw 與 meshlet cluster culling → UE5 Nanite → 光影剔除 → mesh shader 的三角形剔除。

Bevy 教學：用 Rust 做你的第一個 3D 編輯器

系列第一集，用 Rust + Bevy 0.19 做一個 Blender 風格的迷你 3D 場景編輯器：可環繞的相機、無限地面網格、彩色座標軸。程式碼註解很密，附 ECS 概念圖解。

Gravity — Solar System Simulator

qunabu 用 TypeScript + Three.js 做的太陽系模擬。 所有貼圖都是程式生成的 （含土星卡西尼縫、木星大紅斑），採用 J2000 曆元的真實天體資料。有 24 步的導覽教學 ，從重力基本概念 → 二體問題 → 軌道力學 → 3D 運動 → 完整太陽系；可切換 Kepler 解析解與 N-body 牛頓模擬（含即時能量漂移指標），也可切真實比例 / 視覺比例。

前端 / Web

Build your own React

Rodrigo Pombo 的名篇（2019）。八個步驟從零重建 React 16.8 核心： createElement → render → Concurrent Mode（ requestIdleCallback ）→ Fiber → Render/Commit 分離 → Reconciliation → 函式元件 → Hooks（ useState ）。看完會真正懂 Fiber 是什麼。

Grid Garden

Codepip 的經典小遊戲：寫 CSS Grid 語法來澆水種胡蘿蔔。支援 40+ 語言（含中文）。同系列還有 Flexbox Froggy 和 Anchoreum。

Making Software

Dan Hollick 寫作並繪製的軟體參考手冊： 7 萬字、600+ 張插圖、32 章 ，講顏色、螢幕、圖形、渲染、shader、編譯器、直譯器等東西「實際上怎麼運作」。定位不是教學而是查閱型手冊，不需技術背景。目前 early access 數位版，Advanced Edition 售價 *$149*（含未來更新、詞彙表、技術插畫課程、首刷實體書資格）。

資料庫與工具

Learn Git Branching

Pete Cottle 做的老牌神器。模擬終端機裡打真的 git 指令， 右邊即時畫出 commit tree 怎麼變化 。rebase、cherry-pick、reset 這些抽象操作看一次就懂。也支援 Mercurial。

SQL Police Department

Doron Linder 設計，用辦案破案的方式學 SQL：SELECT/FROM、WHERE、ORDER BY、DISTINCT、LIMIT、IN、BETWEEN、AND/OR。 有免費試玩案件，完整授權約 $20 ；作者說彙總函數、GROUP BY、JOIN 的關卡還在製作中。

機器人

Internal Combustion Engine

Bartosz Ciechanowski，2021。這個人的每一篇都是網路互動教學的天花板。從最基本的力與扭矩開始：曲柄 → 引擎缸體 → 曲軸 → 活塞與連桿 → 汽缸頭/氣門/凸輪軸 → 燃燒與噴油點火。 每個 3D 模型都能用滑鼠拖著轉、拉滑桿看行為。 如果整份清單只能看一個，選這個。

Bittle X Simulator

Petoi 出的四足機器狗 Bittle X 的 線上即時模擬器 ：可以編譯自己的控制程式碼、用 WASD 操控、切換站立/復位模式，實體機器人到手前先在瀏覽器裡試。

MuscleWiki

互動人體肌肉圖： 點身上任何一塊肌肉，就列出針對它的訓練動作 ，附 2000+ 支示範影片與正確姿勢說明。免費、免註冊，另有熱量、巨量營養素、1RM 計算機。
