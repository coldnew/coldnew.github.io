    Semantic radar needs more MAP space.

    記憶體關鍵地址（T210）

    • • DMA 緩衝：0x40005000 / 0x40009000，交替使用
    • • 執行棧向下生長，棧底緊貼 0x40010000
    • • RCM payload 載入於 0x40010000，上限 0x30000

    為何能提權

    • • 驗證在收完之後：未驗證 payload 已先寫入記憶體
    • • IROM 漏洞：size_to_tx = length_read，memcpy 溢出棧
    • • 劫持在 lockout 之前：fuse 未鎖定，BPMP 任意執行

    實作要點

    • • fusee-launcher.py + intermezzo.bin + 終端 payload
    • • 64-bit Linux USB3（xhci）或 macOS，需支援大控制請求
    • • 緩衝區不合時多送一個 0x1000 區塊，確保打到上緩衝
